🎲 Game Twists (Optional)

Spice up the game with these optional features!

Each safe tile reveals how "hot" or "cold" it was to the bomb — like Battleship!

Decoys look identical to the real bomb. Finding one gives a false alarm (+1 bonus point) and the game continues!

If set below 100%, finding the real bomb triggers a spin. Failing relocates the bomb and play continues!
